# Обновление Atlantis v0.5 → v0.6 (тестовая версия)

1. В PowerShell **старой папки v0.5** выполни `docker compose down`. **Не добавляй `-v`**: том с PostgreSQL нужен для сохранения регистраций и вопросов.
2. Распакуй новый ZIP, открой папку `atlantis_bot` с файлом `compose.yaml`.
3. Скопируй свой `.env` из предыдущей папки **только на своём компьютере**. Не отправляй `.env` или его скриншот. `TEST_MODE=true` оставь для испытаний.
4. Нажми на адресную строку Проводника, введи `powershell`, Enter. Выполни `docker compose up --build -d`.
5. Проверь `docker compose ps`. Если видишь ошибку или бот не отвечает, выполни `docker compose logs --tail=50 bot` и скрой секреты перед отправкой скриншота.
6. В Telegram отправь Майе `/preview`, затем `/menu`. Ты должна видеть «Путь героя» (как Super Admin в тестовом режиме), а по кнопке — три карточки заданий.
7. Открой любую задачу, отправь **видеокружочек**, затем фото или текст, нажми «Сдать задание». Бот должен подтвердить отправку. Для второй проверки возьми **другую** задачу: одно и то же задание разрешено сдать только один раз.
8. Введи `/participant`, затем `/menu`. Если твоего ФИО **нет** в списке выезда, «Путь героя» пропадёт; «Лекции и мастер-классы» останутся.
9. Для возврата к раннему просмотру используй `/preview`. Спикеров тестовый просмотр показывает заранее; обычный режим покажет их только с 12:10 МСК в день соответствующей лекции.
10. Вопросы Майе и прежняя закрытая группа должны остаться подключёнными, так как привязка хранится в PostgreSQL.

### Что сейчас НЕ включено

Автоматический запуск сюжетных рассылок (22.11 14:00, 24.11 13:30, 27.11 16:00) и напоминаний ещё требует отдельной реализации. Это **не публичный релиз**. Обычные администраторы, экстренные рассылки и группа проверки заданий также будут доработаны после согласования пользовательской части, по решению организатора. Не размещай ссылку на бота публично до этой проверки.

### Важно о белом списке участников выезда

80 ФИО взяты из предоставленного списка. Сверка строгая с учётом регистра/буквы «ё», ФИО привязывается к одному Telegram ID; чужое имя всё ещё можно ввести вручную, поэтому эта проверка **не заменяет подтверждение личности**. При сомнениях понадобится проверка организатором до начисления баллов. Не распространяй архив: он содержит список участников выезда. По соображениям приватности эти данные хранятся только на локальном компьютере/сервере организаторов.
