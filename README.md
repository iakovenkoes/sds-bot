# ATLANTIS — бот Майи, локальная тестовая версия v0.6

Проект для @atlantis_sha26_bot: Python 3.12, aiogram 3, PostgreSQL 16, Docker Compose.

**Важно:** это рабочая промежуточная сборка для локального тестирования, НЕ полная публичная версия ША’26. Для публичного выпуска ещё нужны кодовые слова, билеты, рассылки, проверка в четырёх темах, резервные копии и полный интеграционный прогон. Не распространяйте ссылку участникам до завершения разработки.

## Новое в v0.6
- Участники могут сдавать видеокружочки наряду с текстом, фотографиями, обычными видео и файлами; каждый материал добавляется к черновику до отправки.
- При нажатии «Путь героя» бот отправляет сразу три картинки для блоков «Архив», «Разведка», «Сборка», затем меню блоков; «Погружение» скрывает задания до выезда для обычных пользователей.
- «Путь героя» **скрыт** от пользователей, не подтверждённых по 80 ФИО из документа организаторов. Допуск проверяется и при открытии старых кнопок, и при отправке задания.
- ФИО участника связывается с Telegram ID при первом точном совпадении со списком. Это базовая организационная сверка, а не проверка паспорта; при сомнениях организатор проверяет личность.
- Данные лектора и полная тема появляются **ровно в 12:10 МСК** в соответствующий день, без массовой рассылки. Превью главного администратора может видеть их раньше.
- Утверждённые сюжетные дропы записаны в `data/scheduled_messages_agreed.json` для будущего планировщика. **Никаких автоматических массовых рассылок эта версия не выполняет.**
- Подключённая группа вопросов Майе сохраняется. Админские роли и группа проверки работ — следующий этап, по решению организатора.

## Коротко об установке
1. Docker Desktop должен показывать **Engine running**.
2. Распаковать проект, открыть папку `atlantis_bot` с `compose.yaml`.
3. Перенести **свой** `.env` из v0.5 в новую папку; **не отправлять его в чат**.
4. Проверить `TEST_MODE=true` для локального просмотра.
5. Из PowerShell в новой папке запустить `docker compose up --build -d`.
6. Проверить `/menu`, `/preview`, `/participant`, `/admin` в Telegram.

Полная инструкция безопасного обновления в `UPDATE_FROM_V05.md`.

## Как подключить закрытую группу вопросов
1. Создай **одну закрытую обычную Telegram-группу** для организаторов (без тем).
2. Добавь в неё @atlantis_sha26_bot. Убедись, что ему разрешено отправлять сообщения и фото/файлы. Для надёжной доставки ответов на Reply можно назначить бота администратором этой группы.
3. От своего Telegram-аккаунта Super Admin отправь в группе команду `/bind_support` (если команда не распознаётся — `/bind_support@atlantis_sha26_bot`). Бот должен подтвердить подключение.
4. В личном чате Майи нажми «Вопрос Майе» и отправь тестовый вопрос, он появится в группе.
5. Ответь **через Reply на сообщение, которое прислал бот в группе**, либо нажми «Ответить» и ответь через Reply на подсказку. Участнику придёт ответ от Майи.
6. Нажми «Закрыть вопрос». Следующее обращение этого же участника станет новым тикетом. О закрытии участник отдельного уведомления не получает.
7. Пока отвечать на вопросы может только главный администратор. Позднее добавим назначение роли `support` сотрудникам через `/admin`.

Привязка группы сохраняется в PostgreSQL, повторно вписывать её ID в `.env` не нужно.

## Разделы в разработке
- Кодовые слова и счастливые билеты: сейчас кнопки являются заглушками.
- Полноценная обработка работ в четырёх темах, резервное копирование, права дополнительных администраторов, рассылки по расписанию, импорт Excel — в следующих версиях.
- Для других администраторов пока не реализована самостоятельная выдача доступа в интерфейсе.

## Безопасность
Файл `.env` должен оставаться только на твоём компьютере/сервере и не входить в ZIP. В чате запрещено присылать скриншоты с токеном и паролем. В ходе обновления НЕ использовать `docker compose down -v` — это удалит PostgreSQL-том. Обычный `docker compose down` данные не удаляет.
