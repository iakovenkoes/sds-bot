# ATLANTIS v0.8 — обновление c v0.7

1. Не удалять `.env` и PostgreSQL-тома. Скопировать `.env` из старого каталога в новый `atlantis_bot`.
2. После восстановления Docker Desktop и проверки `Engine running` выполнить `docker compose down` в старом каталоге (без `-v`).
3. В новом каталоге выполнить `docker compose up --build -d`.
4. Проверьте `/admin` и `/admins` в Telegram.

## Администраторы
Шесть Telegram ID из `data/initial_admin_ids.json` добавляются при первом запуске v0.8.
Если пользователь ещё не отправлял `/start`, его права будут назначены при первом `/start`.
Это **одноразовый импорт**. Можно снять назначение с помощью `/removeadmin ID` без повторного добавления при перезапуске.
Седьмого и восьмого человека добавлять вручную: `/addadmin ID` от имени главного администратора.
Главный админ определяется только `SUPER_ADMIN_ID` в `.env`, никакие ID из JSON не становятся супер-админами.

## Сообщения
Стили жирного и курсива из `ответы майи .docx` импортированы в каталог и в статические обработчики.
Telegram HTML допускает только ограниченный набор форматирования; цвет/шрифты Word не поддерживаются.
Сюжетные автоматические рассылки по-прежнему не реализованы; наличие текста в каталоге НЕ означает отправку по расписанию.

## Примечание
Кодовые слова/счастливые билеты и группа проверки заданий требуют отдельной реализации и тестов.
Не включайте публичный запуск до их проверки.
