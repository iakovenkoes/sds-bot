# ATLANTIS • передача человеку для сервера (статус v0.2)

**Внимание:** это НЕ окончательный архив для публичного размещения. Сейчас предназначен для локального теста функционального каркаса. По окончании разработки требуется отдельная приёмка всех функций, резервных копий, расписаний и работы групп.

## Что будет передаваться на финальном этапе
- Исходный проект из `atlantis_bot/` с Dockerfile, Compose, кодом Python, PostgreSQL, задачами и реестром сообщений.
- Инструкция по развёртыванию и миграциям БД, чек-лист ввода в эксплуатацию.
- Токен и секреты будут переданы владельцем отдельно и безопасно; в ZIP их нет.

## Сервер
- Linux/VPS с доступом к api.telegram.org; Docker Engine + Docker Compose Plugin.
- Настроенные переменные окружения `.env`; секреты не хранятся в Git/архиве.
- Доступ для отправки сообщений в закрытые группы поддержки/проверки и права бота в них.
- Фиксированный часовой пояс расписаний: Europe/Moscow; системное время сервера может быть UTC.
- Для polling не запускать параллельно локальную и серверную копию с одним токеном.
- PostgreSQL data volume хранится постоянно, резервные копии отдельно от сервера. Для чистого переноса базы использовать pg_dump/pg_restore.
- Проверить часовые границы дат и дублирующиеся рассылки на тестовой БД перед открытием регистрации.

## Команды после готовности проекта
`docker compose up --build -d`, `docker compose ps`, `docker compose logs -f bot`, `docker compose down`.

Не использовать `docker compose down -v` для рабочей базы.
