# ATLANTIS v0.16 — обновление с v0.15

Исправлена опасная логика группы «Вопросы Майе»: **обычные Reply больше не пересылаются участникам**, даже если ответ дан на исходное обращение или на ответ другого администратора. Это внутреннее обсуждение.

Чтобы **отправить ответ участнику**, администратор должен ответить через Reply на сообщение, связанное с обращением, и написать **`/answer Текст ответа`**. Майя отправит только текст после команды, подтвердит доставку и сохранит ID доставленного сообщения для последующего редактирования.

Сохранены команды:
- Reply на отправленный ответ: `/edit_reply Новый текст` — редактирование сообщения у участника, если оно было отправлено после внедрения хранения ID.
- Reply на связанное сообщение: `/correct_reply Исправленный текст` — отдельное исправление старого ответа.

Существующая кнопка «Ответить» под обращением теперь предлагает команду `/answer` вместо обычного Reply.

**Важно:** при переходе на v0.16 предупредите всех администраторов: прежний способ «просто Reply» больше не отправляет ответы участникам. Отправка только по `/answer`.

## Обновление сервера
1. Сохранить резервную копию PostgreSQL и `.env`.
2. Заменить код приложения на v0.16, сохранив текущую конфигурацию и Docker Compose project/volume.
3. Пересобрать и запустить только бот: `docker compose up -d --build`.
4. Проверить `docker compose logs --tail=150 bot` (название сервиса может отличаться).
5. На тестовом обращении проверить: обычный Reply не доставляется, `/answer Привет` доставляется, `/edit_reply ...` редактирует.

Не используйте `docker compose down -v`: эта команда удаляет тома с данными.
