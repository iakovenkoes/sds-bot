# ATLANTIS v0.15 — исправление ответов в «Вопросы Майе»

- Новая команда `/edit_reply новый текст`: в группе поддержки ответьте (Reply) на **исходное текстовое сообщение администратора**, которое было доставлено участнику уже на v0.15. Майя изменит ранее отправленный ответ непосредственно в личном чате участника.
- Для сообщений, отправленных до обновления, команда `/correct_reply правильный текст` (Reply на исходное сообщение администратора) отправляет участнику новое сообщение с пометкой «Исправление предыдущего ответа». Старый ответ при этом остаётся — его Telegram ID не сохранялся в прежних версиях.
- Команды доступны администраторам и сотрудникам с ролью support, только в подключённой группе «Вопросы Майе». Для медиаответов `/edit_reply` недоступна; используйте `/correct_reply`.
- Новая таблица `support_sent_replies` создаётся автоматически при штатном старте приложения через `Base.metadata.create_all`. Существующие таблицы и данные не изменяются.
- Обновлять с сохранением прежних `.env`, PostgreSQL и Docker Compose volume. Не выполнять `docker compose down -v`.
- Проверьте команды на тестовом обращении после деплоя. Исправления отправляются сразу, без дополнительного подтверждения.
