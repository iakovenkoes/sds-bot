# Обновление ATLANTIS с v0.4 до v0.5 (Windows)

1. Открой PowerShell в **старой** папке v0.4 (`...\ATLANTIS_bot_code_v0_4\atlantis_bot`).
2. Выполни `docker compose down` и убедись, что старые контейнеры остановлены. **Не добавляй `-v`!**
3. Скачай ZIP v0.5, нажми «Извлечь всё», открой **новую** папку `atlantis_bot`.
4. Скопируй `.env` из старой папки v0.4 в новую. Если `.env` уже существует, замени его своей сохранённой конфигурацией.
5. Проверь, что в `.env` есть `TEST_MODE=true`. **Не пересылай файл и не делай скриншот его содержимого.**
6. В Проводнике новой папки щёлкни по адресной строке, напиши `powershell`, Enter.
7. Выполни `docker compose up --build -d`.
8. При необходимости убедись, что всё работает: `docker compose ps`. Если Майя не отвечает — `docker compose logs --tail=50 bot` (скрой секреты перед скриншотом).
9. В Telegram отправь Майе `/menu`, `/preview`, `/participant`, `/admin`.

Данные регистраций и баллов остаются в томе `atlantis_bot_pgdata`. После обновления код создаст новые таблицы поддержки, не удаляя старые. Для локального тестирования можно использовать ту же базу. Перед публичным запуском тестовые записи необходимо отделить от настоящих данных.

Новые фотографии `data/hero_cards/*.jpg` уже включены в архив. Отдельно копировать их не нужно.
