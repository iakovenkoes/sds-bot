# Обновление ATLANTIS v0.3 → v0.4 на Windows

**Что изменилось:** кнопки «Архив», «Разведка», «Сборка», «Погружение» вместо Research/Practice/Theory/Action; после регистрации и отмены добавлена кнопка «🏠 Главное меню». Задания и баллы не менялись. «Погружение» доступно участникам только 28 ноября с 10:00 МСК; до этого главному администратору доступен тестовый предпросмотр.

## Как обновить без потери данных
1. В PowerShell **старой папки v0.3** выполни `docker compose down` **без `-v`**. Это остановит оба контейнера, но оставит базу в Docker volume.
2. Распакуй `ATLANTIS_bot_code_v0_4.zip`. Внутри открой папку `atlantis_bot` с `compose.yaml`.
3. Скопируй **свой** `.env` из старой папки `v0_3/atlantis_bot` в новую `v0_4/atlantis_bot`. Не используй `.env.example` вместо него. Не публикуй `.env` или скриншоты с токеном.
4. Для раннего предпросмотра убедись, что в `.env` сохранено `TEST_MODE=true` (только для главного администратора).
5. Из адресной строки новой папки запусти `powershell`, выполни `docker compose up --build -d`.
6. В Telegram отправь `/menu`, открой «🏆 Путь героя» и «📚 Лекции и мастер-классы», проверь новые кнопки.
7. Если бот не отвечает, выполни `docker compose ps` и `docker compose logs --tail=60 bot`; не показывай секреты.

**Сохранение PostgreSQL:** база лежит в томе `atlantis_bot_pgdata`, если внутреннее имя папки `atlantis_bot` не изменялось и `COMPOSE_PROJECT_NAME` ранее не задавался. Команд `docker compose down -v`, `docker volume rm` или удаления Volumes в Docker Desktop **не используй**.

**Перед публикацией:** `TEST_MODE=false`, перезапуск; всё ещё не готова полная система рассылок, кодовых слов, билетов и групп.
